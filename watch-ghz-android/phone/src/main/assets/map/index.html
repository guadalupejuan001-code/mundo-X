GUÍA DEL MAPA

El espacio, captura a captura.

3D muestra posiciones X, Y, Z. 4D añade el tiempo entre capturas. No representa una cuarta dirección espacial.

  1. Explora. Gira con un dedo, pellizca para acercar y toca un punto. Los círculos ajustan el modelo; los rombos lo ponen a prueba.
  2. Compara. Las flechas del corte Z son predicciones de un dipolo situado en el origen más un campo uniforme. Los puntos son las muestras del archivo.
  3. Avanza. Reproduce las capturas o mueve la línea de tiempo. Cada captura se ajusta de forma independiente; no se inventan mediciones entre ellas.

Campos + objetos

El laboratorio añade 12 partículas de prueba con q/m = 100.000 C/kg. El campo magnético usa el modelo del mapa y el factor B virtual. La gravedad newtoniana procede de una esfera virtual de densidad uniforme; las partículas pueden atravesarla. Las paredes reflejan las partículas. No hay fuerzas entre partículas ni efectos cuánticos. El tiempo mostrado es tiempo simulado y puede avanzar más despacio si el dispositivo no alcanza el ritmo de dibujo.

Para cargar tus mediciones

Un CSV con las columnas de la #59. Cada captura necesita al menos 8 posiciones TRAIN y 4 posiciones HOLDOUT, distintas y separadas por la resolución indicada.

role,frame,x_m,y_m,z_m,time_s,resolution_m,bx_uT,by_uT,bz_uT

Para una secuencia 4D, añade snapshot y snapshot_time_s. Un CSV sin esas columnas se interpreta como una sola ventana estática, aunque sus lecturas tengan tiempos diferentes.

Para que el mapa tenga significado físico: usa posiciones conocidas en metros, el mismo origen, orientación común de los vectores y un sensor calibrado. El campo debe ser aproximadamente estático dentro de cada captura.

El JSON actual del reloj no incluye posiciones ni orientación de referencia. Todavía no permite reconstruir un mapa espacial por sí solo. Las lecturas en vivo usan los ejes del reloj, sin una posición 3D conocida, y no se insertan como puntos del mapa. Esta versión recibe órdenes del mando en el reloj mientras ambas apps están abiertas. Las órdenes modifican el mapa virtual; no generan superposición física.

Los archivos se procesan en este navegador. No se suben a un servidor. Conserva el CSV exportado: al cerrar o recargar, el visor vuelve a la demo. La escala de color se mantiene fija durante toda la secuencia.
