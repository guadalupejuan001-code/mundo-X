# Quantum Core X v0.1

Esta capa ancla Mundo X a matemáticas cuánticas reales.

## Estado

Para n qubits:

|psi> = sum(alpha_k |k>)

con:

sum(|alpha_k|^2) = 1

Las amplitudes son complejas; por eso la fase relativa forma parte del estado.

## Primitivas incluidas

- vector de estado complejo normalizado
- superposición mediante Hadamard
- rotación de fase
- Pauli-X
- CNOT
- estado de Bell entrelazado
- interferencia
- medición y colapso

## Qué demuestra

Demuestra únicamente que Mundo X puede representar y evolucionar estados
cuánticos válidos dentro de un simulador clásico.

No demuestra ventaja cuántica ni hardware cuántico nuevo.

## Por qué va antes de Transformer X

Transformer X debe conectarse después a un estado que ya obedece reglas
cuánticas. De lo contrario solo estaríamos llamando "cuántico" a
procesamiento ondulatorio clásico.
