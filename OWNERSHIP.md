# Autoría, propiedad y dependencias

El proyecto declara **Mundo X Language (MX)** como lenguaje propio y fuente canónica futura.

El código original, documentación, formatos y especificaciones creados para Mundo X corresponden al titular del repositorio, sujeto a los derechos que puedan aplicar a contribuciones o materiales de terceros.

Esta declaración **no** convierte en propiedad del proyecto a C++, Python, Java, Android, Linux, OpenGL ES, Vulkan, GitHub Actions, Gradle, CMake, CPU ISAs, bibliotecas, estándares, algoritmos publicados ni otros componentes externos. La migración busca reducir/eliminar su presencia como fuente activa, no reclamar derechos sobre ellos.

El historial Git conserva procedencia y autoría de cada revisión. La asistencia de herramientas de IA no cambia por sí sola la titularidad legal; la situación exacta depende de jurisdicción, acuerdos aplicables y material de terceros.
